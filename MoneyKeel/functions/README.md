# functions

**Lives here:** The maths: every calculation the app makes, one family per file, its test beside it.

Named `functions`, not `engines` — the word engine was decommissioned by the vocabulary standard
on 2026-08-25. What produces a figure is a FUNCTION; the one that answers a whole question by
calling the others is an ORCHESTRATOR FUNCTION.

**Never here:** Screens, wording, colours.

Six sub-folders, the same six under every top folder: networth-and-performance, cashflow,
retirement, home-screen, other, standards.
