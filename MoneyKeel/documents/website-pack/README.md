# MoneyKeel website pack

1. `FEATURES.md`: what MoneyKeel is, who it's for, what each part of the app does, what makes it different, and a caption for every screen.
2. `BRAND.md`: the look and feel, including colours (with hex values), type sizes, shapes, and do's and don'ts.
3. `screens/`: 16 iPhone screens as PNG (2× resolution), numbered in a sensible order for a home page. All of them use sample data only.
4. `logo/`: the wordmark, the "K" mark (PNG and SVG) and the app icon.
5. Start with FEATURES.md, then BRAND.md. Keep the calm, plain-spoken tone, and claim nothing the app doesn't do.
