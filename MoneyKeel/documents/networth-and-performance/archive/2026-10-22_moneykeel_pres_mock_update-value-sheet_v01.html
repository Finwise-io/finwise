Update value sheet — v01, drawn from today’s code

The sheet a person opens to change the value of an account built by hand, drawn over the account page in every state the code has (A to H, one phone, each state top to bottom). It was built before it was drawn; this drawing closes that gap.

READ THIS FIRST — what this drawing is, and what it was drawn from
#WhatWhyDecision
1The sheet that changes the value of an account built by hand, as the app shows it today: a cash account, a bond, an amount cleared, an alternative whose value is 7 months old, its page after keeping the value, the sheet opened from its box, its page after saving, and a value with no date.The sheet was built with no drawing behind it. Every state of updating a value by hand must be drawn.DEC-0470
2Drawn from src/screens/AccountPortfolioScreen.tsx: the sheet and the three buttons that open it. Each state was rendered with its own account on Sep 30, 2026, and every word, colour and size was read off that render. Colours are the tokens of src/utils/theme.ts.A drawing of what is built is taken from the code, never from an older drawing.—
3Under the sheet, dimmed, is the top of the account page, as built. The page’s design is the approved account-page drawing v01. Muni 2029 here is v01’s state B, with the same figures.One design per screen. This drawing adds only what v01 does not show.DEC-6457
4The phone’s own parts are drawn but not checked: the status bar, the number keyboard, the blue typing cursor and the orange state labels. The keyboard is up because the amount is ready for typing the moment the sheet opens.The phone draws them, not MoneyKeel.—
5The sheet opens with the account’s value already filled in, in digits with no comma: the same figure as its market value. Saving stamps today as the value’s date, written the app’s one way. An amount of 0, or none, greys the save button; no sentence says why (state C).Drawn as built.MK-NW-M-018 (market value) · MK-ST-F-078 (dateShown)
6Three ways in: the button under the walk (A, B), the button in the box shown when a value is 6 or more months old (F), and the button in the box shown when a value has no date (H). Keeping the value instead only moves its date to today (E).Every door to the sheet is drawn.MK-NW-F-003 (valueFreshness) · DEC-0013
7Held word for word, in order, by src/screens/__tests__/update_value_sheet_drawing.test.tsx. On Oct 20, 2026 every line matched the built screen, in order: A, B, C and F, 5 of 5 on the sheet and 24 of 24 above it; D 67 of 67; E 64 of 64; G 64 of 64; H 55 of 55.A drawing the build can drift from is not a design.—

STATE G · state F after 8400 is entered and saved

  • Value as of Sep 30, 2026: the date the sheet named ✓; the box is gone ✓
