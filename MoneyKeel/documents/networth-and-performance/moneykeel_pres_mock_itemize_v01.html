Itemize an account — v01

The screen that opens from the Net worth account sheet, from “Itemize this account into holdings”. It breaks a single lump-sum balance into the real holdings inside it while a meter counts down what is still unplaced, and it keeps the account total from moving.

Drawn from the code, not from another mock. Every string, size, colour and radius here is read from src/screens/ItemizeScreen.tsx and src/utils/theme.ts.

What “from Build 53” means here. Build 53 shipped this screen at commit 263f741. It has changed by 58 lines since, in three commits, and only three of those changes are visible — all three are rulings of yours:
• “Stock / ETF” became “Stock / Fund” (the Stocks / Funds sweep).
• the title went from 24 points to 20 (screen titles at 20 points, 2026-09-14).
• the arithmetic moved behind the one door, MK-NW-O-002 theAccount — same numbers, asked once (Q-NW-2, 2026-09-27).
So this is drawn as Build 53 plus those three rulings. Drawing it literally would put retired wording and a retired type size back on the page, and the canon guard would refuse it.
Two things the code does that you should see before approving. Both are drawn above exactly as they happen; neither is a suggestion.

1 · The header says “itemize”, in lower case. The route is not declared in app/_layout.tsx, so it takes the navigator's defaults — including a title that falls back to the route name. Every other pushed screen in the app has its title set there.
2 · There are two ways out, side by side. The navigator draws a back arrow and the screen draws its own ✕ on the same line as the heading.

A · NOTHING PLACED YET — the state you land in

The whole balance sits unallocated, the bar is empty, and Done is disabled because no holding has been added. No leftover note yet: the code shows it only once at least one holding exists.
