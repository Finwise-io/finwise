2026-10-04 · DEC-1669 · his words: “All return should be True Weighted Return and not Dietz return.”
Every return on these phones is now a time-weighted return: the window is split at each day money moved in or out, each piece is measured, and the pieces are multiplied. Money added is never counted as earned. Figures: MK-PF-M-016, MK-PF-M-017, MK-XS-M-004.

1. The words “money-weighted, so money you added never counts as return” read “time-weighted, so money you added never counts as return”. On one account’s page the note ends “· time-weighted”.
