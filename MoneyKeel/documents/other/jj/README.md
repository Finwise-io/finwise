# The founder's own files

Files JJ writes himself — feedback workbooks, marked-up screens, his answered copies. They keep his
filename and carry `-jj`, or simply sit here.

**No script ever writes to, overwrites or renames anything in this folder.** It is an input of
record and is kept forever. The file-and-folder naming pattern does not apply here, by the same rule.

Once a file here has been read and written into the original, it moves to `../JJ-feedback-archive/` with the date as a prefix (founder, 2026-09-10).
