Which figures have a function, and which do not

All 163 figures a person can read, with the label exactly as it appears and the screen it appears on. The 69 without a function are not one problem — they are three, and only one of them is fine. Grouped exactly as the master file groups them: a figure shown on more than one parent screen is its own group, never folded into whichever screen is named first.

94
Have a function
A named function in the code produces the figure. Traceable end to end.
52
No function on record
Nothing in the file says what produces this. Most were named while reading a screen and never traced back.
12
Worked out on the screen
Arithmetic done in the screen file itself. A place a second definition can appear, and none of it is tested.
5
Typed — none needed
The person entered the number. Nothing calculates it, and nothing should. These are correct as they are.
