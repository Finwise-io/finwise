MoneyKeel — the engine bench

Type a number, watch every figure recompute — through the REAL engine code the app ships, compiled straight from the same files. Nothing here is a copy or a mock-up of the math. Built __BUILT_STAMP__.

How to use: every white box on the LEFT of a card is yours to type in — the answers on the RIGHT recompute with every keystroke. Cards with a dashed box also take a dropped file. Nothing you type or drop leaves this machine.
Runs entirely on this machine. The Vanguard preset, where present, is embedded from the local file and this page is never committed to git.
