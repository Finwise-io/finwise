# Flow screens — mocks v1 (2026-08-10)

The 19 screens that had no section structure to band mechanically. Each is drawn FROM the shipping
screen (its own title, sections and actions), restyled to the adopted design, and each file shows
TWO states side by side: with data, and empty/first-day.

Design applied to every one:
- deep-green section band in white caps (`#085041`), white card body
- one shared right-aligned value column, with the tap arrow in its own slot after it
- the EMPTY-STATE RULE: the full layout stays with honest blanks — never a stripped screen
- the one type scale and theme colors already shipped app-wide
