# FinWise rename — name shortlist + domain availability (2026-07-01)

**Brief:** signal "Money Command Center"; short; easy to pronounce; no spelling confusion; **prefer `.ai`, then `.io`.**

**Reality:** every clean single dictionary word (Keel, Helm, Poise, Vantage, Anchor, Beacon, Compass, Haven, Nest,
Even, Summit, Ledger, Cockpit, Steady, Harbor, North, Tally) is **TAKEN on `.com`, `.co`, `.ai`, AND `.io`.** Short
single-word domains are a scarce/expensive resource. So a single word requires flexing to `.co` (available) or
buying a premium domain; otherwise the play is **compound or coined.**

## Cautions
- **Trademark / collision:** common words are already used in finance/tech — Compass (real estate), VantageScore,
  Ledger (crypto wallet), Nest (Google), Anchor (crypto/podcasting), Beacon (credit). **Lower-collision: Keel,
  Poise, Cockpit, Helm, Tally, Even.** A USPTO + app-store check is required before committing.
- **`.co`/`.io`/`.ai` vs `.com`:** the 36-65 / 65+ audience skews trust-sensitive and types `.com` by habit — pair
  any `.co`/`.ai` pick with a `.com` companion (e.g., `getkeel.com`, `keel.money`).
