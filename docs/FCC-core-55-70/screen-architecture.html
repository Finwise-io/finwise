C · Decisions for the founder

The questionWhat is true todayThe choice
Tips and Rewards are strandedNothing links either. Trimmed from the menu 2026-08-02 and left behind. Retire them like /income (recorded keeps), or give them a door.
/savings can only be opened during onboardingIts only link is the onboarding summary, so no existing user can reach it. Give it a door, fold it into Cash flow, or record it as retired.
Where does monthly income belong?An income screen, but four Plan-side screens link to it. Cash flow (my lean) or Plan · Retire.
Does Plan really need three sub-tabs?Retire is the whole redesign; Goals and Prepare are existing screens. Three sub-tabs, or one Retire surface with the rest in the ☰ menu.
Nine screens have exactly one doorEach is one deleted link away from being unreachable — how /big-costs broke. Accept it (the guard now catches it), or add second doors to the important ones.
How to trust this page. The top half is generated, so it cannot drift from the code — if a screen loses its last door, this page says so the next time it is run. The middle and bottom halves are written by hand and change only when someone decides something.
